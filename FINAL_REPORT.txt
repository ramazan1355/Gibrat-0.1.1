🧪 ТЕСТИРОВАНИЕ:
════════════════════════════════════════════════════════════════════════

✓ Регистрация новых пользователей
  1. Откройте рег.html
  2. Заполните форму
  3. Нажмите "sing up"
  4. Проверьте в Firebase → Authentication

✓ Вход в систему
  1. Используйте созданный аккаунт
  2. Заполните email и пароль
  3. Нажмите "login"
  4. Должны попасть на home.html

✓ Профиль пользователя
  1. Откройте проф.html
  2. Должны видеть ваше имя и email
  3. Нажмите "Редактировать профиль"
  4. Измените данные и сохраните

✓ Выход (logout)
  1. На проф.html нажмите кнопку "Выход"
  2. Должны попасть на login.html
  3. Откройте DevTools → LocalStorage
  4. Данные должны быть очищены

✓ Навигация
  1. Кликайте на вкладки внизу
  2. Активная вкладка должна светиться
  3. Переход между страницами должен работать

✓ Защита страниц
  1. Очистите localStorage
  2. Откройте home.html напрямую
  3. Должны попасть на login.html
