## 🚀 Как начать:

1. Откройте `run-server.bat` (Windows)
2. Откройте `http://localhost:8000/login.html`
3. Нажмите "Register here"
4. Заполните форму и создайте аккаунт
5. Проверьте в Firebase Console → Authentication
6. Проверьте данные в Firestore → users коллекция

## ⚠️ Важно:

1. **Для production:**
   - Используйте environment переменные вместо явного API ключа
   - Установите правила Firestore (см. SETUP_COMPLETE.md)
   - Используйте HTTPS только
   - Добавьте rate limiting

2. **Безопасность:**
   - Не публикуйте API ключ в публичный репозиторий
   - Используйте httpOnly cookies для хранения токенов
   - Валидируйте данные на сервере
   - Используйте CORS правила

3. **Производительность:**
   - Кэшируйте данные профиля
   - Используйте lazy loading для изображений
   - Минифицируйте JavaScript
   - Используйте CDN для статических файлов
