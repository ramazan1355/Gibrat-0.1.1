📊 FIRESTORE СТРУКТУРА:
═════════════════════════════════════════════════════════════════

Коллекция: users
├─ Документ: {uid пользователя}
│  ├─ uid                 (строка)
│  ├─ fullName           (строка)
│  ├─ email              (строка)
│  ├─ avatar             (URL)
│  ├─ bio                (строка)
│  ├─ theme              (light/dark)
│  ├─ courses            (массив)
│  ├─ level              (beginner/...)
│  ├─ registrationTime   (timestamp)
│  └─ lessonsCompleted   (массив)

🔍 ПРОВЕРКА:
═════════════════════════════════════════════════════════════════

1. Откройте run-server.bat (Windows)
2. Откройте http://localhost:8000/login.html
3. Нажмите "Register here"
4. Заполните форму и создайте аккаунт
5. Вы попадёте на home.html
6. Откройте DevTools → Application → LocalStorage
7. Должно быть: userLoggedIn, userData, currentUserId
8. Проверьте: https://console.firebase.google.com
   ├─ Authentication → ваш новый пользователь
   └─ Firestore → users → ваш документ


⚠️ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
═════════════════════════════════════════════════════════════════

Проблема: "Модули не загружаются"
→ Решение: Используйте локальный сервер (run-server.bat)

Проблема: "Firebase не инициализируется"
→ Решение: Проверьте интернет, посмотрите DevTools → Network

Проблема: "Не сохраняются данные"
→ Решение: Проверьте правила Firestore в Console

Проблема: "Ошибка при входе"
→ Решение: Проверьте консоль ошибок (DevTools → Console)
