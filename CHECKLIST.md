## Как начать работу:

### 1. Запустить сервер
```bash
# Windows
run-server.bat

# Mac/Linux
./run-server.sh
```

### 2. Открыть браузер
```
http://localhost:8000/login.html
```

### 3. Создать аккаунт
- Нажать "Register here"
- Заполнить форму
- Нажать "sing up"

### 4. Проверить в Firebase
- https://console.firebase.google.com
- Проект: gibrat-8b273
- Authentication → увидите нового пользователя
- Firestore → users → документ пользователя

### 5. Тестировать функции
- Навигация между страницами
- Чат с ментором
- Редактирование профиля
- Выход из системы
- Повторный вход

## 📞 Быстрая справка:

### Добавить новую страницу:
1. Создать HTML файл
2. Скопировать скрипты из другой страницы:
```html
<script type="module" src="firebase-config.js"></script>
<script type="module" src="firebase-auth.js"></script>
<script src="profile-manager.js"></script>
<script src="navigation.js"></script>
```
3. Добавить навигационный бар с ссылками

### Добавить новую функцию:
1. Создать новый JS файл в папке gibrat
2. Написать функцию с обработкой ошибок
3. Подключить скрипт к нужным HTML файлам
4. Экспортировать функцию в window (если нужно)

### Интеграция нового API:
1. Добавить коллекцию в Firestore
2. Создать методы в firebase-auth.js
3. Вызывать методы из своих скриптов
4. Сохранять данные в localStorage для кэша
